# Pig Game

Juego de dados para dos jugadores hecho con **JavaScript vanilla**, sin librerías.

**[Jugar la demo](https://pig-game-three-sandy.vercel.app/)**

## Cómo se juega

- En tu turno tiras el dado tantas veces como quieras y vas acumulando puntos.
- Si sale un **1**, pierdes los puntos del turno y pasa el turno al rival.
- Pulsa **Hold** para guardar los puntos acumulados en tu marcador.
- Gana quien llegue primero a **20 puntos**.

## Qué trabajé

- Manipulación del DOM y gestión de eventos.
- Estado del juego (jugador activo, marcadores, partida terminada).
- Planificación previa con un diagrama de flujo (`pig-game-flowchart.png`).

## Tecnologías

`HTML` `CSS` `JavaScript`

## Ejecutar en local

Clona el repositorio y abre `index.html` en el navegador.
